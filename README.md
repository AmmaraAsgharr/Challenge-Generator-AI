# ⚡ ChallengeAI

ChallengeAI is a modern web application designed to help users build positive habits through daily challenges. The platform generates random challenges from multiple categories and allows users to track their progress over time.

## Features

- 🔐 User Authentication (Login & Signup)
- 🎯 Random Challenge Generator
- 💪 8 Challenge Categories
- 📋 Challenge Tracker & Progress Monitoring
- 🌤️ Weather-Based Suggestions
- 🖼️ Interactive Challenge Gallery
- 🌙 Dark/Light Theme Toggle
- 📱 Fully Responsive Design
- 💾 Session Storage for User Data

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Web APIs
- Session Storage

## Categories

- Fitness
- Mindfulness
- Creativity
- Learning
- Social
- Nutrition
- Productivity
- Adventure

## Project Objective

The goal of ChallengeAI is to encourage personal growth by providing users with engaging daily challenges and helping them build consistency through progress tracking.
